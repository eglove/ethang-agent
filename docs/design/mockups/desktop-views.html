3 — OPTION B: dockable IDE panes not recommended

Drag any view anywhere, stack them, save layouts. Full control — and months of Avalonia work (a docking library or a hand-rolled one), plus a permanent layout tax on every future view. The dashed boxes are what you would spend that time on.
