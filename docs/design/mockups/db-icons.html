Database icon candidates

Unicode has no official database-cylinder emoji. These are the closest shapes, in the app theme at strip size.

🛢️
Oil drum
U+1F6E2
Literally a cylinder — the classic DB silhouette. Semantically odd (oil drum), but the shape everyone recognizes.
🗄️
File cabinet
U+1F5C4
Storage, not a cylinder. Reads as archive rather than database.
🗃️
Card file box
U+1F5C3
Records in a box. Database-ish, no cylinder.
💽
Minidisc
U+1F4BD
Storage media, but flat — not the stacked-platter glyph.
⛁
Draughts king
U+26C1
A stack of discs — literally the DB platter shape. Risk: monochrome text glyph in some fonts, and not an emoji.
🖴
Hard disk
U+1F5B4
Real disk glyph, but text-presentation by default — often renders small/monochrome.
🧱
Brick
U+1F9F1
No. Listed to rule it out.
